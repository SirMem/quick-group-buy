# 拼团营销上下文

本上下文描述拼团营销系统中活动、试算、锁单、组队、结算、退单和通知协作时使用的业务语言。它只定义领域术语，不记录实现细节或技术方案。

## Language

### 活动与优惠

**拼团活动**:
面向某个来源、渠道和商品配置的营销活动，定义拼团目标、有效时间、参与次数限制和优惠规则。一个**拼团活动**可以产生多支**拼团队伍**。
_Avoid_: 活动、营销活动、团购活动

**营销商品**:
参与**拼团活动**试算或锁单的商品视图，包含商品、用户、来源和渠道。它不是商城侧完整商品档案。
_Avoid_: 商品、产品、SKU

**优惠试算**:
在用户下单前，根据**拼团活动**、商品、用户和人群限制计算可见性、可参与性、原始价格、优惠金额和应付金额。
_Avoid_: 预结算、价格查询、折扣计算

**优惠规则**:
拼团活动中用于计算优惠金额的规则，例如直减、满减或固定价格购买。优惠规则可以受人群标签限制。
_Avoid_: 折扣表达式、营销计划

**人群限制**:
拼团活动对特定用户群体设置的可见或可参与边界。用户可能看不见活动，也可能看得见但不能参团。
_Avoid_: 标签、用户分层、权限

### 组队与交易

**拼团队伍**:
同一拼团活动下，为达成目标人数而形成的一组参团关系。拼团队伍有目标人数、锁单人数、完成人数和组队状态。
_Avoid_: 团、组、team

**营销锁单**:
为某个用户、商品和**外部交易单号**锁定参团资格与优惠结果的业务事实。锁单后用户可能支付成功，也可能超时未支付或退单。
_Avoid_: 下单、占库存、预购

**锁单人数**:
已完成**营销锁单**但不一定已经支付成功的参团人数。锁单人数用于防止队伍超过目标人数。
_Avoid_: 参团人数、支付人数

**完成人数**:
已经完成支付并参与结算的参团人数。完成人数达到目标人数时，拼团队伍可以完成。
_Avoid_: 成团人数、支付人数

**外部交易单号**:
调用方传入拼团营销系统的交易标识，用于把拼团锁单、支付结算和退单反向流程关联到同一笔外部支付订单。
_Avoid_: 订单号、交易号、商户订单号

**预购订单**:
拼团营销系统内部记录的一次参团交易意图，关联用户、拼团队伍、优惠结果和外部交易单号。
_Avoid_: 支付订单、商城订单、交易订单

**交易订单状态**:
预购订单在拼团营销侧的状态，目前包括初始创建、消费完成和用户退单。
_Avoid_: 支付状态、商城订单状态

**拼团结算**:
外部支付成功后，拼团营销系统确认预购订单完成消费，并推动拼团队伍完成人数增长、成团判断和后续通知。
_Avoid_: 支付结算、商城结算

**组队状态**:
拼团队伍当前所处的业务位置，目前包括拼单中、完成、失败和完成含退单。
_Avoid_: 订单状态、交易状态

### 退单与通知

**退单**:
用户或外部系统撤销一次参团交易意图的业务动作。退单可能释放锁单人数，也可能在已支付场景下触发外部系统退款。
_Avoid_: 退款、取消、关单

**退单类型**:
拼团营销根据是否支付、是否成团判断的退单分类，目前包括未支付未成团、已支付未成团、已支付已成团。
_Avoid_: 退款类型、退单策略

**反向库存**:
退单后对锁单人数或组队统计进行恢复的业务动作，使拼团队伍容量回到正确状态。
_Avoid_: 回滚库存、恢复库存

**回调通知**:
拼团营销在组队完成或退单完成后，通知外部系统继续履约或退款的业务动作。通知可以通过 HTTP 或 MQ 完成。
_Avoid_: 消息、任务、回调任务

## Flagged ambiguities

**商品 / 营销商品**:
拼团营销侧只关心用于优惠试算和活动匹配的商品视图，因此本上下文使用**营销商品**；商城侧完整售卖对象仍称为**商品**。

**外部交易单号 / 商户订单号**:
在商城支付上下文中，同一个值叫**商户订单号**；在拼团营销上下文中，它是调用方传入的**外部交易单号**。讨论跨上下文协作时，需要说明当前站在哪个上下文说话。

**锁单人数 / 完成人数**:
锁单人数表示占住队伍名额但未必支付，完成人数表示支付后完成结算。不能把锁单人数当作成团人数。

**拼团结算 / 支付成功**:
支付成功发生在外部支付或商城支付上下文；拼团结算发生在拼团营销上下文。拼团营销只根据外部传入的支付成功事实推进结算。

**退单 / 退款**:
拼团营销处理的是参团关系的退单和反向库存；资金退款属于外部支付或商城支付上下文。

## Example dialogue

> 开发：用户打开商品页时，拼团营销先做什么？
>
> 领域专家：先做优惠试算，判断这个用户是否看得见、能不能参与，以及如果参团可以优惠多少钱。
>
> 开发：用户决定参团以后，拼团营销就算成团了吗？
>
> 领域专家：不是。参团时只是营销锁单，锁住优惠和队伍名额；用户支付成功以后，商城支付再通知拼团营销做拼团结算。
>
> 开发：锁单人数达到目标人数就算完成吗？
>
> 领域专家：不算。锁单人数只是占位，完成人数才表示已支付并结算。完成人数达到目标后，拼团队伍才完成。
>
> 开发：如果用户退单，拼团营销负责退款吗？
>
> 领域专家：拼团营销负责退单分类和反向库存。如果已经支付，需要通过回调通知商城支付去执行资金退款。
